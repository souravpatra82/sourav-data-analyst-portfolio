- `index.html` — Portfolio page structure and content.
- `style.css` — Website styling, layout, and responsive design.
- `script.js` — JavaScript functionality, including mobile navigation and footer year.
- `icons/` — SVG icon assets used by the portfolio.
- `analytics-illustration.png` — Analytics illustration referenced by the website.

## Run Locally

1. Keep `index.html`, `style.css`, `script.js`, the `icons/` folder, and image assets together in the project directory.
2. Open `index.html` in your web browser.
3. Test the website on desktop, tablet, and mobile screen sizes.
4. Check that navigation, buttons, images, and JavaScript interactions work as expected.
